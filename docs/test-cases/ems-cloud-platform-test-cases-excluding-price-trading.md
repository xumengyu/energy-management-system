# EMS 云平台测试用例

> 范围说明：本文覆盖 EMS 云平台除 `Price & Trading` 菜单下功能之外的测试用例。当前环境访问 `https://platform.aiwatt.net:8090/` 时连接被关闭，以下用例基于仓库中的功能清单、侧边栏路由、页面文案与组件行为整理。执行时建议以实际线上页面为准补充截图、接口返回和缺陷编号。

## 1. 测试范围

### 1.1 覆盖范围

- 账号与安全：登录、登出、忘记密码、注册入口、个人资料、修改密码、会话与权限。
- 全局能力：电站切换、语言切换、主题切换、侧边栏、消息入口、用户菜单、移动端适配。
- 资产总览：资产 KPI、趋势图、能源分布、站点列表、地图/站点分布入口。
- 电站管理：站点列表、查询筛选、新建/编辑/删除电站、支路/馈线配置、设备分配。
- 架构监视：电站架构图、节点状态、节点详情、站点切换。
- 实时监控：实时总览、实时详情、ESS/PV/EVSE/DG 分类、设备下钻、刷新、CSV 导出。
- 数据分析：功率分析、SOC 分析、电池簇分析、自定义分析、筛选、报表和导出。
- 能源统计：负荷、储能、光伏、充电桩、柴油发电统计。
- 告警管理：告警查询、日期/等级/状态筛选、分页、详情、确认处理。
- 控制与保护：手动控制、PCS/BMS/IO/除湿机/空调/柴发控制、保护策略。
- 收益管理：收益概览、收益结构、收益趋势、收益明细与导出。
- 主体/组织管理：管理员、邀请、组织结构、账单订阅、安全设置。
- 非功能：性能、兼容性、安全、可用性、国际化、审计追溯。

### 1.2 明确排除范围

以下为 `Price & Trading` 菜单下功能，本轮不纳入测试用例：

- Execution View / 执行视图
- AI Dispatch / 调度编排
- Manual Dispatch / 手动调度 / 我的策略模板
- Price List / 电价列表
- Station Price Config / 电价配置
- 动态电价、价格模型、市场电价源、交易策略、云调度下发等与 Price & Trading 直接关联的流程

如实际部署中 `AI Dispatch Optimizer` 被产品定义为 Price & Trading 的一部分，也应排除；若其作为独立 AI Dispatch 模块发布，可单独建立专项用例。
