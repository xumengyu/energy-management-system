## 测试说明

1. 线上地址会重定向到 `/login`；本次未获得有效登录账号，因此登录后的模块用例依据当前前端实现与文案结构编写，执行时需补充具备对应权限的测试账号。
2. 线上登录页实测语言只有 `English` 与 `Français`；本地前端源码同时存在中英文业务文案。国际化用例需按实际部署语言包确认。
3. 注册、找回密码涉及验证码发送。测试时应使用专用测试邮箱，避免向真实用户发送邮件。
4. 策略下发、手动控制、保护策略保存等属于可能影响设备状态的高风险操作。联调环境执行前需确认边缘设备为模拟网关或测试站点。
5. 已有专项文档：`docs/test-cases/station-branch-config.md` 覆盖支路配置细节，本文只保留整站级入口和主流程用例。

## 通用前置条件

- 浏览器可访问 `http://223.6.248.244:8090/eco-watt/`。
- 测试账号已准备：管理员账号、普通操作员账号、只读账号、无权限账号。
- 测试数据已准备：至少 3 个站点，覆盖正常、告警、离线状态；至少 1 个带 BESS/PV/EVSE/DG 设备的微网站点。
- 涉及编辑、删除、下发、控制的用例优先在测试环境执行。
