## 数据合理性核查

| 核查项 | 结论 | 说明 |
|--------|------|------|
| PV 汇总功率 | 合理 | PV1-PV10 每台约 `40.2-40.3 kW`，合计约 `402-403 kW`，与 PV Monitor `402.5 kW` 匹配 |
| 架构图功率平衡 | 基本合理 | `Load 4264.35 kW ≈ Grid 3853.05 kW + PV 411.30 kW + BESS 0 kW` |
| BESS SOC | 基本一致 | 实时详情 BESS1 `4.9%`、BESS2 `4.8%`，架构图 `4.85%`；但实时概览显示 `0` 不一致 |
| BESS 温度 | 合理 | 单体/设备温度约 `27-32°C`，未见异常极值 |
| 电网频率 | 合理 | BESS 详情中 `Pcs Frequency Grid [Hz] = 50.00` |
| PV 状态 | 不合理 | 架构图显示 PV `Deconnecte`，但同时有 `411.30 kW` 输出 |
| 当日 PV 电量 | 需确认 | 能量统计 PV `Generation Totale 8.8 kWh`，相对 `402.5 kW` 实时功率偏低；若统计周期刚开始可解释，否则需核查累计口径 |

## 时区问题

| 问题编号 | 严重级别 | 现象 | 判断 |
|----------|----------|------|------|
| TZ-001 | P1 | 执行视图显示 `2026-06-04 08:20:50`，数据分析图表截止约 `08:20` | 这符合 Portuguese Farm 所在葡萄牙夏令时当地时间 |
| TZ-002 | P1 | 实时详情显示 `Derniere mise a jour: 04/06/2026, 15:20:06`；AI 调度页显示 `2026-06-04 15:20:55` | 这更像浏览器/中国时区时间，与同一电站其他页面的 `08:20` 不一致 |
| TZ-003 | P2 | 日期选择器在法语环境下显示 `2026年6月` | 语言/日期格式未按当前语言或站点地区统一 |

## 缺陷汇总

| 缺陷编号 | 优先级 | 描述 | 影响 |
|----------|--------|------|------|
| BUG-PF-001 | P1 | Portuguese Farm 的不同页面时间口径不一致：部分使用葡萄牙当地时间 `08:20`，部分使用 `15:20` | 影响实时性判断、调度时间理解和运维排障 |
| BUG-PF-002 | P1 | 架构图设备状态与功率矛盾：PV `Deconnecte` 但输出 `411.30 kW` | 影响运行状态判断 |
| BUG-PF-003 | P1 | 实时概览 BESS SOC 显示 `0`，与详情页/架构图 `4.8%-4.9%` 不一致 | 影响核心储能状态判断 |
| BUG-PF-004 | P2 | 法语界面混用英文、中文文案：`2026年6月`、`Cancel`、`Apply`、部分图表标题和按钮英文 | 影响国际化体验 |
| BUG-PF-005 | P2 | 能量统计 PV `Generation Totale 8.8 kWh` 与当前 `402.5 kW` 实时功率存在口径疑问 | 需要确认是当日、月累计还是当前窗口累计 |

## 结论

切换到 `Portuguese Farm` 后，大多数核心数据页面可以展示有效数据，且 PV 汇总功率、架构图功率平衡、BESS 详情参数整体合理。当前最需要优先处理的是时区口径不统一、架构图状态与功率矛盾、实时概览 SOC 与详情不一致这三类问题。
